# Roadmap

A community-driven roadmap for Retro Puzzle Game. This project prioritizes community feedback and contributions.

## Vision

Create the best 90's-style puzzle game experience with community contributions, maintaining vanilla JavaScript simplicity while adding engaging features.

## Priority Criteria

Features are prioritized by:

1. **Community Demand** - How many people want it?
2. **Implementation Complexity** - How much work?
3. **Scope** - Does it stay true to retro game vision?
4. **Dependencies** - Does it block other features?
5. **Backwards Compatibility** - Does it break existing gameplay?

## Known Limitations

### Current Constraints
- Vanilla JS (no frameworks) - keeps it simple
- Canvas-based (no WebGL) - better compatibility
- No backend (no servers) - easier to host
- Browser-only - not a native app
- Single-player (for now) - planned for v2.0

### Performance Targets
- 60 FPS on modern devices
- Works on 5-year-old hardware
- Mobile-friendly (<5MB total)
- <100ms input latency
